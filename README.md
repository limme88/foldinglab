# Folding Lab

Website for Folding Lab, a research mentorship program for high school students in Irvine, California.

The whole site is one file, `index.html`, with four pages (Home, Projects, Mentor, Contact) that the menu at the top switches between. Open it in a browser to preview it; there is no build step.

The site is published with GitHub Pages from the `main` branch: https://limme88.github.io/foldinglab/
